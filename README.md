- [**UNIA SaaS**](https://github.com/LFPE/UNIA) — Plataforma B2B Multi-Tenant com controle de acesso (RBAC) para gestão escalável de SLAs e rotinas operacionais.

- [**Organizador PowerShell**](https://github.com/LFPE/organizador-arquivos-powershell) — Automação de rotinas de infraestrutura Windows para higienização e organização lógica do sistema de arquivos.
- [**Second Brain**](https://github.com/LFPE/second-brain) — Ambiente arquitetado no Obsidian para gestão de conhecimento estruturado, visando retenção de informações técnicas e produtividade.
